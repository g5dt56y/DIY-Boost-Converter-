# DIY Boost Converter

This is a custom 2-layer Boost Converter PCB designed from scratch in KiCad. 

## Features
- **Input:** 5V DC
- **Output:** Adjustable up to 12V DC
- **Controller:** NE555 Timer
- **Manufacturing:** Fabricated via PCBWay

## Repository Contents
- `/KiCad_Files` - Source schematics and PCB layout.
- `/Gerbers` - Manufacturing-ready files.
- `/Images` - 3D renders and physical board photos.
